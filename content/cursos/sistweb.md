## Dia, Hora e Local

3as, 19-22h

## Objetivo

Apresentar tópicos de pesquisa relacionados à web. Para tal, faremos uma revisão dos conceitos básicos da web, introduziremos tópicos de pesquisa com apresentações, implementação de trabalhos práticos e discussões de artigos. 

## Tópicos

- Arquitetura Web
- Common Gateway Interface
- Programação em Rede
- Linguagens de Programação no Cliente (Navegador)
- Tipos de Escopo
- Persistência e Rastreamento de Clientes
- Linguagens de Programação no Servidor (Servidor Web)
- Modelagem de Sistemas Web
- Padrões de Aplicações Web
- Frameworks de Aplicações Web
- Metalinguagem XML e algumas linguagens afins
- Enriquecimento de Aplicações Web (RIA)
- Acessibilidade na Web
- Web Services
- Definição de APIs
- Recuperação de Dados na Web
- Mineração de Dados na Web
- Big Data
- Linked Data
- Linked Open Data e Semântica na Web
- Agentes de IA
